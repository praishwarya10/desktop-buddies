# Desktop Buddies website V2

Multi-page static website. Open index.html for design preview, or serve the folder with `py -m http.server 8000` for full local testing.

Pages: index.html, explore.html, spiderman.html, itachi.html, about.html, privacy.html, terms.html, 404.html.

## Download buttons
Copy your own built installers into `downloads/` using these exact names:
- SpiderMan-Desktop-Buddy-Setup-1.0.0.exe
- Itachi-Study-Buddy-Setup-1.0.0.exe

## Video demos
Both character pages contain deliberate demo placeholders. Replace them with recorded MP4/WebM elements later.

## Before publishing
Check intellectual property permissions for the characters and art, finalize legal/contact copy, test signed installer distribution and shortcut conflicts, and verify downloads on a hosted server.
